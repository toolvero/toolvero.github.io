What is Base64?

Base64 is a text encoding that represents binary or textual data using a restricted ASCII character set. It is common in APIs, configuration files, certificates and data URLs. Base64 is encoding, not encryption, and should not be treated as a security mechanism.

Common uses

  • Encode text for transport in text-based systems.
  • Decode Base64 values while inspecting configuration or API data.
  • Quickly verify whether a Base64 payload contains expected text.
