Common TCP and UDP ports

This is a quick operational reference, not a complete IANA registry. Always verify application-specific port requirements in vendor documentation.

Why use a common ports reference?

Network troubleshooting often starts by identifying which service normally uses a TCP or UDP port. A searchable reference provides quick context for familiar ports such as 22, 53, 80 and 443 while investigating firewall rules, listeners or connectivity.

Common uses

  • Search by exact port number or service name.
  • Identify common services during network troubleshooting.
  • Use the result as a reference; applications can be configured on non-standard ports.
