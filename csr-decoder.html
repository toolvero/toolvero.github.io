Why decode a CSR?

A CSR contains the identity and public key submitted to a certificate authority. This tool helps verify the requested common name and other attributes before a certificate is issued.

What is a CSR?

A certificate signing request contains a public key and identifying information that is sent to a certificate authority when requesting a certificate. Inspecting the CSR helps verify names and request details before a CA signs it.

Common uses

  • Check the subject before submitting a CSR.
  • Verify request information during certificate troubleshooting.
  • Compare a CSR with the certificate that was later issued.
