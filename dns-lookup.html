DNS-over-HTTPS lookup

This tool queries DNS records through a public HTTPS resolver so it can work from a static GitHub Pages site. Do not enter confidential internal hostnames.

What does a DNS lookup do?

DNS translates domain names into records used by browsers, mail systems and other network services. Looking up records such as A, AAAA, MX, TXT, CNAME and NS is a common first step when troubleshooting name resolution, mail routing or domain configuration.

Common uses

  • Check IPv4 and IPv6 address records.
  • Inspect MX and TXT records during mail or domain troubleshooting.
  • Verify DNS changes using a public resolver.
