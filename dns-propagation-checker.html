DNS Propagation Checker

Compare current answers from multiple public resolvers.

Results from available public DNS-over-HTTPS resolvers will appear here.

What does DNS propagation mean?

After a DNS record changes, recursive resolvers can continue serving cached data until relevant TTLs expire. Comparing multiple public resolvers can reveal differing current answers, but no small set of resolvers can prove that a change has propagated everywhere.

Common uses

  • Compare DNS answers during a record change.
  • Check whether two public resolvers currently agree.
  • Use alongside a direct DNS lookup when troubleshooting cached records.
