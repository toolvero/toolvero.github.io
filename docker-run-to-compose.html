Docker Run → Compose

Convert common docker run options into a Compose YAML service. No command is executed or sent anywhere.

From docker run to Docker Compose

The converter handles common options including container name, ports, environment variables, volumes, restart policies, working directory, user, hostname, networks and detached mode. Review generated YAML before production use because Docker CLI supports many advanced flags.
