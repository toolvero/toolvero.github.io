Parse dotenv files safely

This utility handles comments, optional export, quoted values and inline comments after unquoted values. Values remain strings, matching typical environment-variable behavior. Processing happens locally in your browser.

What is a .env file?

A .env file is a simple convention for storing environment-variable assignments used by applications and development tools. Converting entries to JSON can make values easier to inspect or move into systems that expect structured configuration.

Common uses

  • Parse KEY=value lines into JSON.
  • Handle comments, export prefixes and quoted values.
  • Never paste production secrets or access tokens into online tools.
