DNS Records Explained: A, AAAA, CNAME, MX, TXT and NS

A practical reference for the DNS record types administrators see most often.

DNS maps names to data

The Domain Name System stores typed records. A lookup is not limited to IP addresses: DNS also publishes mail routing, aliases, authoritative name servers and text used by verification and email-security systems.

TypeTypical purpose
AHostname to IPv4 address
AAAAHostname to IPv6 address
CNAMEAlias one name to another name
MXMail exchanger for a domain
TXTText data such as verification, SPF or other policy data
NSAuthoritative name servers for a DNS zone
DNS LookupDNS Propagation Checker

TTL and cached answers

DNS records include a time-to-live value that tells recursive resolvers how long an answer may be cached. After a record changes, different resolvers can temporarily return different answers because their caches were populated at different times.

MX priorities

MX records include a preference value. Lower values have higher preference. Multiple records can provide redundancy, but actual mail delivery behavior also depends on the receiving servers and sender implementation.

Troubleshooting sequence

  1. Query the exact record type you expect.
  2. Confirm the authoritative configuration.
  3. Check TTL and whether recursive resolvers still have cached answers.
  4. For mail issues, inspect MX plus relevant TXT records.
