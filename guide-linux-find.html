Linux find Command Examples

Practical Linux find examples for names, file types, modification time, size and safe cleanup workflows.

Find files by name

find /var/log -type f -name '*.log' -print

Quote wildcard patterns so the shell does not expand them before find receives the pattern.

Find files by modification age

find /var/log -type f -name '*.log' -mtime +30 -print

-mtime +30 is commonly used to select files older than the specified day count. Test the exact result set before combining age filters with destructive actions.

Filter by size

find /var/log -type f -size +100M -print

This example finds regular files larger than 100 MiB-equivalent find units denoted by M.

Safe cleanup workflow

First run the filters with -print. Only after reviewing every match should you consider -delete or an -exec action. Be especially careful when running as root.
