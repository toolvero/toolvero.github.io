Hash and HMAC utility

Generate SHA-1, SHA-256, SHA-384 and SHA-512 digests or HMAC signatures locally. HMAC combines a secret key with the selected hash algorithm for message authentication.

What is the difference between a hash and HMAC?

A cryptographic hash produces a fixed-size digest from input data. HMAC combines a cryptographic hash with a secret key to provide message authentication. That distinction matters when validating integrity versus proving that a party with the shared secret created a value.

Common uses

  • Compare plain hashes with keyed HMAC output.
  • Generate values for development and interoperability testing.
  • Use test secrets rather than production credentials in browser utilities.
