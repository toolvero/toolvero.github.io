HTTP Status Codes Reference

Quick reference for common 1xx, 2xx, 3xx, 4xx and 5xx responses.

Search common HTTP status codes.

How are HTTP status codes grouped?

HTTP response codes are grouped by class: informational 1xx, successful 2xx, redirection 3xx, client error 4xx and server error 5xx. The code provides a compact indication of how a server handled a request.

Common uses

  • Look up a code seen in API or web logs.
  • Distinguish client-side 4xx errors from server-side 5xx errors.
  • Use standard reason phrases while troubleshooting HTTP responses.
