Check IPv4 subnet membership

This tool compares the binary network portion of an IPv4 address with a CIDR block. It is useful when reviewing firewall rules, routes, allowlists and subnet assignments.

How do you check whether an IP is inside a CIDR?

An IPv4 address belongs to a CIDR network when the network portion of the address matches the network defined by the CIDR prefix. This tool performs the calculation and also shows useful boundaries such as the network, broadcast and usable host range.

Common uses

  • Validate whether a host belongs to an expected subnet.
  • Troubleshoot firewall or allow-list CIDR rules.
  • Check network boundaries before assigning an address.
