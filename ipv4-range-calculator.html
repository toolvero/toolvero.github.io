What does an IPv4 range calculator show?

An explicit first-to-last IPv4 range is useful in firewall, inventory and address-management work. The calculator counts the inclusive addresses and finds a single smallest CIDR block that contains the full range; that CIDR can include addresses outside the original range.

Common uses

  • Count addresses in an IPv4 start/end range.
  • Find a single CIDR that contains an existing range.
  • Compare explicit ranges with subnet boundaries.
