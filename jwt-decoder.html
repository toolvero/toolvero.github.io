What is a JWT decoder?

JWTs contain Base64URL-encoded header and payload sections. Decoding is not the same as signature verification, so never treat decoded claims as trusted without verifying the signature.

What is a JWT?

A JSON Web Token is a compact format used to carry claims between systems. A JWT commonly contains a header, payload and signature. Decoding the first two sections lets you inspect claims such as issuer, audience and expiration, but decoding alone does not prove that the token is authentic.

Common uses

  • Inspect claims while debugging authentication.
  • Read exp and other timestamp-based fields.
  • Remember that this tool decodes the token; it does not verify its signature.
