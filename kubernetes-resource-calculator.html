Calculate Kubernetes resource totals

Multiply per-container requests and limits across replicas and containers per Pod. This is useful when estimating the aggregate CPU and memory represented by a workload configuration.

Scheduling note

Requests influence scheduling while limits constrain runtime resource use. Cluster overhead, DaemonSets, system workloads, autoscaling and real utilization are separate considerations.
