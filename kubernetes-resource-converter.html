Kubernetes resource units

CPU requests and limits commonly use cores or millicores, while memory uses binary units such as Mi and Gi. This converter helps translate values quickly when editing manifests.

How are Kubernetes CPU and memory resources expressed?

Kubernetes commonly expresses CPU in cores or millicores, such as 500m for half a CPU core. Memory quantities use units such as Mi and Gi. Converting these values helps when reviewing requests, limits and capacity across manifests and workloads.

Common uses

  • Convert millicores to CPU cores.
  • Translate Mi and Gi memory quantities.
  • Review resource requests and limits more quickly.
