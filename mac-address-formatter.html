MAC Address Formatter & Validator

Normalize a MAC address locally in your browser.

Enter a MAC address to validate or reformat it.

Why normalize MAC addresses?

Network platforms display hardware addresses in several conventions. Normalizing the same 48-bit value makes it easier to move between switch, firewall, inventory and troubleshooting workflows.

Common uses

  • Convert Cisco dotted notation to colon notation.
  • Validate copied MAC addresses before using them in configuration.
  • Normalize addresses for documentation or inventory.
