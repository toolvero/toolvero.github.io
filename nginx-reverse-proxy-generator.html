Nginx Reverse Proxy Generator

Build a practical Nginx reverse proxy configuration locally in your browser.

Ready.

What does this Nginx generator create?

It creates a starting-point server block for a reverse proxy. The generated configuration includes common proxy headers and optional WebSocket handling. Production TLS, caching, timeouts, access controls and application-specific requirements still need review.

Common uses

  • Create a reverse proxy server block quickly.
  • Add common X-Forwarded-* and Host headers.
  • Generate a WebSocket-ready proxy configuration.
