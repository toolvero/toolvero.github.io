How do Linux permissions work?

Linux permissions define read, write and execute access for the file owner, group and others. Numeric chmod notation represents each permission set with a value from 0 to 7, while symbolic notation uses the familiar r, w and x characters.

Common uses

  • Translate rwxr-xr-x into chmod 755 and similar values.
  • Check permissions before applying chmod to a file or directory.
  • Learn how owner, group and other permission bits map to numbers.
