What is a regular expression tester?

Regular expressions describe text patterns used for validation, searching and transformation. Testing a pattern against representative input makes it easier to find escaping, grouping or matching mistakes before the expression is placed into application code.

Common uses

  • Test patterns against realistic sample text.
  • Experiment with common JavaScript regex flags.
  • Check whether a validation pattern matches too much or too little.
