What is SHA-256?

SHA-256 is a cryptographic hash function that produces a 256-bit digest. Hashes are commonly used for integrity checks, identifiers and verification workflows. A hash is one-way and is different from encryption because it is not intended to be decrypted.

Common uses

  • Calculate a digest for text during testing.
  • Compare expected and generated hashes.
  • Use alongside HMAC when learning the difference between hashing and keyed authentication.
