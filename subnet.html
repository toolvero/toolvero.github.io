Subnet Calculator

IPv4 + CIDR → red, máscara, broadcast, rango y cantidad de hosts.

What is an IPv4 subnet calculator?

A subnet calculator converts an IPv4 address and CIDR prefix into the network information administrators use when planning or troubleshooting IP networks. It helps identify the network address, broadcast address, subnet mask and usable host range without doing the binary calculation manually.

Common uses

  • Use it when designing VLANs or address plans.
  • Verify whether a proposed host range fits a subnet.
  • Check network and broadcast boundaries before configuring devices.
