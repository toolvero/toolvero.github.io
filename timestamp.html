What is a Unix timestamp?

A Unix timestamp represents time as the number of seconds elapsed since the Unix epoch at 00:00:00 UTC on January 1, 1970. It is widely used in logs, APIs, tokens and databases because it provides a compact machine-readable time value.

Common uses

  • Convert timestamps found in logs to readable dates.
  • Generate epoch values for API or database testing.
  • Inspect time-related values while debugging JWTs or automation.
