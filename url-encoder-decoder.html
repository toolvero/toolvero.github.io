Percent encoding

URL encoding replaces reserved or unsafe characters with percent-encoded values. This is useful when building query strings, redirect URLs and API requests.

What is URL encoding?

URLs reserve certain characters for structural meaning. Percent-encoding represents characters using a percent sign followed by hexadecimal bytes so values can safely appear in URL components. Decoding reverses that representation for inspection.

Common uses

  • Encode query parameter values.
  • Decode percent-encoded strings from logs or requests.
  • Inspect URLs while debugging web applications and APIs.
