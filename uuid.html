What is a UUID v4?

  
A UUID is a 128-bit identifier commonly used to label records and resources without relying on a central sequential counter. Version 4 UUIDs are generated from random data and are widely used in applications, APIs, databases and distributed systems.

  
Common uses

  
  • Generate identifiers for development and test data.
  • Create IDs for API payloads or configuration examples.
  • Produce multiple UUIDs without installing a command-line utility.
